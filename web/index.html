Tap on the map to set a target. Use your device location and compass to compute signed deviation. Declination is added to magnetic heading to produce true heading.

Use WMM fetch to get official predicted geomagnetic field (NOAA). Enable magnetometer to read actual B from your device (if supported). Add multiple observations (lines-of-bearing) and solve for an estimated target point.
