# Υπολογιστής Συχνότητας Larmor - Μεσσηνία

Μια εφαρμογή web που υπολογίζει τη συχνότητα Larmor χρησιμοποιώντας την εξίσωση **ω = γB**, με ειδική εστίαση στις περιοχές της Μεσσηνίας.

## Τεχνικές Λεπτομέρειες

### Εξίσωση Larmor
```
ω = γ × B
```
Όπου:
- **ω** = Συχνότητα Larmor (rad/s)
- **γ** = Γυρομαγνητικός λόγος (rad/(s·T))
- **B** = Μαγνητικό πεδίο (T)

### APIs
- **NOAA WMM**: World Magnetic Model
- **BGS**: British Geological Survey Magnetic Calculator
- **CORS Proxy**: Για APIs που δεν υποστηρίζουν CORS

### Responsive Design
- Mobile-friendly interface
- Modern gradient design
- Real-time calculations
