# Υπολογιστής Συχνότητας Larmor (NOAA/BGS, live)

Εφαρμογή web (Node/Express + static frontend) που:
- Υπολογίζει τη συχνότητα Larmor: f = (γ/2π) · B
- Φέρνει ζωντανές τιμές γεωμαγνητικού πεδίου B για συγκεκριμένες συντεταγμένες από NOAA NCEI (WMM) και British Geological Survey (WMM)
- Περιλαμβάνει προεπιλογές για περιοχές της Μεσσηνίας και χρήση γεωεντοπισμού συσκευής
- Εμφανίζει πίνακα αρμονικών της f στο εύρος 9–50 MHz

## Εκτέλεση
1) Απαιτείται Node 18+.
2) Εγκατάσταση:
```bash
npm install
```
3) Εκκίνηση (τοπικά):
```bash
npm start
```
- Άνοιγμα: `http://localhost:3000`
- Προσαρμογή θύρας: `PORT=3001 npm start`

Σημείωση για γεωεντοπισμό: Οι browsers απαιτούν HTTPS ή `localhost` για πρόσβαση στην τοποθεσία. Το `localhost` είναι αποδεκτό.

## Χρήση
- Επιλέγετε υλικό (πίνακας με γυρομαγνητικούς λόγους σε Hz/T, δηλαδή γ/2π). Για απόλυτη ακρίβεια μπορείτε να ενεργοποιήσετε «Προσαρμοσμένη γ/2π» και να εισάγετε επίσημη τιμή (Hz/T ή MHz/T).
- Επιλέγετε πηγή πεδίου (NOAA, BGS, ή μέσος όρος).
- (Προαιρετικό) Ορίστε «Ημερομηνία/Ώρα» και «Υψόμετρο (m)» για το ακριβές σενάριο.
- Διαλέγετε περιοχή Μεσσηνίας ή πατάτε «Χρήση τρέχουσας τοποθεσίας».
- Η τιμή B (σε μT/T) συμπληρώνεται αυτόματα με ένδειξη ακριβούς timestamp/συντεταγμένων/υψομέτρου. Πατήστε «Υπολόγισε fL». Θα εμφανιστεί και πίνακας αρμονικών (9–50 MHz).

### Γεωφυσική (διείσδυση & ζώνη)
- Δώστε συχνότητα γεννήτριας (Hz/kHz/MHz), αγωγιμότητα εδάφους σ (S/m), βάθος στόχου.
- Επιλέξτε «Τρόπος στόχου»: Νομίσματα (πλήθος/διάμετρος) ή Μάζα (kg) με πυκνότητα (g/cm³) και σχήμα (σφαίρα/δίσκος με πάχος).
- Για νομίσματα μπορείτε να δηλώσετε «Κιβώτιο πυρομαχικών» με προεπιλογή χωρητικότητας ~3000 νομισμάτων και διαστάσεις επάνω επιφάνειας, ώστε να αυξάνεται η αποτελεσματική επιφάνεια σύζευξης.
- Υπολογίζεται το βάθος διείσδυσης δ = sqrt(2/(ω μ σ)) και μια ευρετική ακτίνα ζώνης αναζήτησης που κλιμακώνεται με την εξασθένηση στο βάθος και το αποτελεσματικό μέγεθος στόχου.
- Πρόκειται για ευρετικό μοντέλο, όχι πλήρη ηλεκτρομαγνητική προσομοίωση.

## Προεπιλεγμένες περιοχές (Μεσσηνία)
- Κυπαρισσία, Φιλιατρά, Μάλη, Σιδηρόκαστρο, Πλατάνια, Καρυές, Στασιό, Μουζάκι

Οι συντεταγμένες είναι προσεγγιστικές. Μπορείτε επίσης να χρησιμοποιήσετε τον γεωεντοπισμό της συσκευής.

## Σταθερές (γ/2π σε Hz/T)
- 197Au ≈ 0.327e6
- 107Ag ≈ −1.088e6, 109Ag ≈ −1.251e6 (το πρόσημο δεν επηρεάζει |f|)
- 63Cu ≈ 11.285e6, 65Cu ≈ 12.089e6
- 27Al ≈ 11.094e6
- 57Fe ≈ 1.375e6 (ενδεικτικό για σιδηρούχα υλικά∙ τα κιβώτια πυρομαχικών 1940 ήταν συνήθως χαλύβδινα)

Οι τιμές είναι τυπικές από βιβλιογραφία NMR και χρησιμοποιούνται ως γ/2π ώστε f σε Hz = (γ/2π)·B σε Tesla.

## Πηγές δεδομένων B
- NOAA NCEI WMM (live, κατά ημερομηνία/ώρα/συντεταγμένες)
- British Geological Survey WMM (live)

Η εφαρμογή υπολογίζει την «ολική ένταση» (Total Intensity, F) και τη μετατρέπει σε Tesla (1 nT = 1e−9 T). Περνά υψόμετρο σε km όπου απαιτείται και δοκιμάζει το πιο πρόσφατο διαθέσιμο μοντέλο (WMM) με εφεδρικές επιλογές.

## API (backend)
- `GET /api/places` — προεπιλογές Μεσσηνίας (όνομα, lat, lon)
- `GET /api/field/noaa?lat=..&lon=..&date=ISO&alt=meters` — επιστρέφει `totalIntensityT`
- `GET /api/field/bgs?lat=..&lon=..&date=ISO&alt=meters` — επιστρέφει `totalIntensityT`
- `GET /api/geocode?q=ονομα` — Nominatim proxy (προαιρετικό)

Σημειώσεις:
- Η υψομετρική τιμή προεπιλογής είναι 0 m.
- Γίνονται κλήσεις προς δημόσιμα endpoints. Εφαρμόζονται περιορισμοί χρήσης/ρυθμοί (rate limits).

## Αρμονικές 9–50 MHz
Μετά τον υπολογισμό f, η εφαρμογή εμφανίζει τις αρμονικές n·f που πέφτουν στο εύρος 9–50 MHz.

## Επιστημονική σημείωση
- Η εφαρμογή παρέχει ακριβείς υπολογισμούς Larmor και ανάκτηση γεωμαγνητικού πεδίου από WMM (NOAA/BGS) με χρονική/χωρική ακρίβεια.
- Η ενότητα «Γεωφυσική» είναι ευρετική για επιτόπια καθοδήγηση και δεν αποτελεί πιστοποιημένο γεωφυσικό όργανο. Πολλοί παράγοντες (στρωματογραφία, μαγνητική επιδεκτικότητα, υγρασία, θόρυβος) επηρεάζουν ισχυρά την πραγματική διάδοση/ανίχνευση.
- Τα δεδομένα NOAA/BGS διέπονται από τους αντίστοιχους όρους χρήσης τους.
- Η χρήση του Nominatim απαιτεί ευγενική χρήση και κατάλληλο User-Agent.
